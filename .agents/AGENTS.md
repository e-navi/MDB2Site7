# プロジェクト行動ルール (AGENTS.md)

## 1. コード修正・ツールの実行条件
- **ユーザーからの明示的な変更・実装指示（例: 「修正してください」「作成してください」「実装してください」等）がない限り、ファイルを書き換えるツール（replace_file_content, write_to_file等）を一切実行してはならない。**
- 「～できますか？」「～可能でしょうか？」「～どうなりますか？」等の質問・ご相談・確認に対しては、**テキストによる解説・確認の回答のみ**を行い、ユーザーからの明示的な指示・承認を待つこと。

## 2. 段階的実装・確認の徹底
- 機能の実装や修正は、ユーザーの指示に基づきステップバイステップで1つずつ確認しながら進めること。
- 指示されていない未要求の追加処理や独断での仕様変更・機能追加は絶対に行わないこと。

## 3. 実装・修正完了時および設定ファイル・ルールの変更時のGitコミット
- 一連の機能実装やコード修正が完了した際は、必ず区切りごとに即座にGitへコミットしてバージョン管理を行うこと。
- AGENTS.md や各種ルール・設定定義ファイルに変更があった場合も、必ず即座にGitへコミットすること。
